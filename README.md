# Warsztat badacza danych — semestr letni 2025/2026

Repozytorium z materiałami i rozwiązaniami laboratoriów z przedmiotu **Warsztat badacza danych**. Zawiera notebooki Jupyter oraz skrypty Python/R do regresji, klasyfikacji, redukcji wymiarów i metod ensemble.

## Struktura

| Folder | Temat |
|--------|--------|
| `01_linear_regression` | Regresja liniowa (SS vs Secchi, TP vs Chla) |
| `02_logistic_regression` | Regresja logistyczna (Crus, Rotif) |
| `03_pca_lda` | PCA i LDA (Iris, Wine, Toxins) |
| `04_svm` | SVM — Support Vector Machine (Wine, VLagun) |
| `05_naive_bayes` | Naiwny klasyfikator Bayesa (VLagun) |
| `06_knn` | k-NN — najbliżsi sąsiedzi (Toxins5, JezPrzym) |
| `07_gains_lift_charts` | Wykresy zysku i wzrostu (gains / lift) |
| `08_pca_dimensionality_reduction` | PCA — redukcja wymiarów (Wine) |
| `09_svm_r` | SVM w R (Wine) |
| `10_decision_tree_random_forest` | Drzewo decyzyjne i las losowy — klasyfikacja |
| `11_random_forest_regression` | Las losowy — regresja |

## Uruchomienie

Zalecane jest lokalne środowisko wirtualne Python oraz Jupyter. Dane CSV leżą w folderach poszczególnych zadań — ścieżki w notebookach wskazują na pliki z tego samego katalogu.
